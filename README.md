# 成語自動化產出

輸入「國語第 N 課　第 M 個成語「XXXX」」→ 自動補齊解釋與例句 → 產出教學圖卡 PNG。

## 目錄
```
data/成語資料.json      成語資料庫（成語・注音・解釋・例句・出處・近反義詞・易錯提醒）
data/播放設定.json      早自習自動播放設定（學期起訖・停課日・播放時段）
scripts/產圖.py         產出教學圖卡（文字排版一律本機做，中文字保證正確）
scripts/gemini_插圖.py  呼叫 Gemini 影像模型產生情境插畫，並接著產出插圖版圖卡
scripts/匯出pptx.py     產出 16:9 PPTX（可直接投影，也可匯入 Canva 編輯）
scripts/匯出csv.py      產出 Canva Bulk Create 用的 CSV
scripts/產出播放頁.py   產出教室電腦早自習自動播放用的 HTML（見下方「早自習自動播放」）
scripts/全部更新.py     一次跑完「匯出csv.py」＋「產出播放頁.py」
output/                 成品圖檔（插畫另存 output/插圖/；播放頁在 output/播放/index.html）
windows/                教室電腦安裝用的排程腳本，見 windows/README_安裝步驟.md
金鑰.txt                放 Gemini 金鑰（已被 .gitignore 排除，不會外流）
```

## 兩種版型
| 版型 | 尺寸 | 產出方式 |
|---|---|---|
| 文字版 | 1600×1200（4:3，投影用） | `python3 scripts/產圖.py` |
| 插圖版 | 1600×1600（上方插畫橫幅） | `python3 scripts/gemini_插圖.py --編號 L01-01` |
| 投影版 | 1920×1080（16:9） | `python3 scripts/產圖.py --投影版` |
| PPTX | 1920×1080，每個成語一頁 | `python3 scripts/匯出pptx.py` |

## 早自習自動播放（教室大螢幕）

每個上課日 **07:30–08:30** 讓教室電腦自動全螢幕輪播「今日成語」＋「複習」，
不需要人手動開關。畫面是純網頁（離線 HTML，不需要網路），跟 Canva 卡片走
同一套配色。

- 「今日成語」的決定方式（`data/成語資料.json` 頂層欄位，由上往下優先）：
  1. `"今日序號": 3` — 手動釘住第（三）則，優先權最高，適合臨時指定
  2. `"今日編號": "L01-03"` — 用內部編號指定
  3. `"自動推進": {"起始日": "2026-09-29", "起始序號": 2}` — 從起始日起，
     每經過一個**上課日**往後推一則；週末、國定假日、停課日都不會消耗進度
  4. 都沒設 → 陣列最後一筆
- 成語播完後會停在最後一則，等你補新的，不會繞回頭重來。
- 「複習」＝排在今日成語**前面**的那幾則（也就是已經教過的），每輪隨機排序。
  還沒教到的不會出現。
- 跑 `scripts/產出播放頁.py` 會印出接下來 12 個上課日的排程，可以先核對再 push。
- 播放時段、學期起訖、停課日都在 `data/播放設定.json`，改完要重跑
  `scripts/產出播放頁.py`（或 `scripts/全部更新.py`）。
- 教室電腦（Windows）第一次要安裝一次排程，之後每天自動觸發，
  完整步驟見 [`windows/README_安裝步驟.md`](windows/README_安裝步驟.md)。
- 本機隨時預覽：瀏覽器打開 `output/播放/index.html`，網址後面加 `?demo=1`
  可以無視時間判斷、直接開始輪播。

## Canva Bulk Create 流程

模板已建好，網址：https://www.canva.com/d/roBD9QbcWO6lO-W （名為「成語卡模板（勿刪）」）

新增成語後，只要重跑匯出、重新上傳 CSV 即可：
```bash
python3 scripts/匯出csv.py
```
然後在模板裡：大量建立 → 上傳 `output/canva批量資料.csv` → 自動比對欄位 → 產生設計。
比對正確時會顯示「13 項符合，共有 17 項」。

### 三個踩過的坑
1. **模板只能有一頁**。模板有 N 頁時，M 筆資料會產出 N×M 頁且內容重複。
2. **PPTX 的文字框不能設垂直置中**。Canva 匯入時會把它轉成「帶文字的形狀」，
   於是被當作圖片欄位、填不進文字。`匯出pptx.py` 已全部改為頂端對齊。
3. **注音是四個獨立文字框**，要分別接 `注音1`～`注音4`，不要接 `注音` 那一欄。
   `注音`、`出處`、`近義詞`、`反義詞` 這四欄版面上沒有對應的框，對不上是正常的。

### 不要按「自動比對欄位」的時機
模板的文字框若還沒掛上欄位標籤，自動比對只能靠文字內容猜，曾把整段「解釋」
塞進 156px 的成語大字框。模板現在每個框都有標籤，自動比對才是安全的。

## 常用指令

產出全部文字版圖卡：
```bash
python3 scripts/產圖.py
```

只產出某一個：
```bash
python3 scripts/產圖.py --編號 L01-01
```

## 接上 Gemini（插圖版）

1. 到 https://aistudio.google.com/apikey 免費申請金鑰
2. 打開專案裡的 `金鑰.txt`，把金鑰貼上去取代「請貼在這裡」，存檔
3. 確認金鑰可用的模型：
```bash
python3 scripts/gemini_插圖.py --列出模型
```
4. 產插畫 + 圖卡一次完成：
```bash
python3 scripts/gemini_插圖.py --編號 L01-01
```

**注意**：`gemini-2.5-pro` 是純文字模型，不會產圖。產圖要用影像模型，
腳本預設 `gemini-2.5-flash-image`。要換模型：
```bash
GEMINI_IMAGE_MODEL=imagen-4.0-generate-001 python3 scripts/gemini_插圖.py --編號 L01-01
```

只想看要交給 Gemini 的指令、不呼叫 API：
```bash
python3 scripts/gemini_插圖.py --編號 L01-01 --只印指令
```

已經有插畫檔（自己畫的或別處產的）放進 `output/插圖/{編號}_{成語}.png`，
也可以直接套版：
```bash
python3 scripts/產圖.py --編號 L01-01 --插圖
```

## 新增成語
在 `data/成語資料.json` 的 `成語` 陣列加一筆，編號規則 `L{課次兩位}-{序號兩位}`，
例如第二課第一個成語為 `L02-01`，然後重跑 `scripts/全部更新.py`
（同時更新 Canva 用的 CSV，以及早自習自動播放頁；新加的這筆會自動變成
播放頁的「今日成語」）。純本機圖卡則重跑 `產圖.py`。
