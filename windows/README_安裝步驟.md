# 教室電腦安裝步驟（只需要做一次）

這份給「學校大螢幕接的那台 Windows 電腦」用。目標：每個上課日早上
**07:30 自動全螢幕播放成語卡、08:30 自動關閉**，不需要人手動操作。

播放內容放在 GitHub Pages 上，所以**裝好之後就不用再碰這台電腦了**——
老師在自己電腦上更新成語並 push，這台隔天早上就會自動播到新內容。

網址：<https://simon05091004.github.io/chengyu-cards/>

## 你會需要
- 那台電腦有 Microsoft Edge（Windows 內建）或 Google Chrome
- 那台電腦早上要連得到網路（斷網有離線快取備援，見最後一節）
- 一次系統管理員權限，把排程裝上去

## 步驟

### 1. 下載檔案
在那台電腦的瀏覽器開：

```
https://github.com/simon05091004/chengyu-cards
```

點綠色的 **Code** 按鈕 → **Download ZIP**。

### 2. 解壓縮，放到 C:\
解壓縮後會得到 `chengyu-cards-main` 資料夾。把它**改名成 `成語卡`**，
然後整個放到 `C:\` 底下。完成後這個路徑要存在：

```
C:\成語卡\windows\安裝排程.ps1
```

（放別的位置也可以，下面指令裡的路徑跟著改就行。）

### 3. 開系統管理員 PowerShell
開始功能表打「PowerShell」→ 對「Windows PowerShell」按右鍵 →
**「以系統管理員身分執行」**。

### 4. 解除封鎖 + 安裝
從網路下載的 `.ps1` 會被 Windows 標記成「來自網際網路」，先解鎖再裝。
一行一行貼進去執行：

```powershell
cd "C:\成語卡\windows"
```
```powershell
Get-ChildItem "C:\成語卡\windows\*.ps1" | Unblock-File
```
```powershell
powershell -ExecutionPolicy Bypass -File .\安裝排程.ps1
```

看到綠色「安裝完成！」就成功了，會建立兩個排程工作：
- `成語卡_開始播放`（每天 07:30）
- `成語卡_停止播放`（每天 08:30）

這兩個排程只在「現在登入的這個 Windows 帳號」有登入時才會觸發。教室電腦
如果是共用帳號、平常都開著或每天會登入，這樣就沒問題。

### 5. 馬上測試
在 `windows` 資料夾雙擊 **`立即測試.ps1`**（或右鍵→使用 PowerShell 執行），
會用一般視窗立刻開始輪播，確認畫面、字級在大螢幕上讀不讀得清楚。

想測真正的全螢幕 kiosk：開「工作排程器」找到 `成語卡_開始播放`，右鍵→執行
（需要現在時間落在 07:30–08:30 之間，否則腳本會判斷不該播而直接結束）。
測完在 `成語卡_停止播放` 右鍵→執行即可關閉。

### 6. 緊急要離開全螢幕
kiosk 模式按 **Alt+F4** 關閉視窗。或到「工作排程器」手動執行
`成語卡_停止播放`。

## 以後有新成語時
**這台電腦完全不用動。** 老師在自己的電腦上：

```bash
python3 scripts/全部更新.py
git add -A && git commit -m "新增成語" && git push
```

推上去之後，教室電腦隔天早上自動播新內容。

改停課日、學期起訖、播放時段也一樣——改 `data/播放設定.json` 後重跑、push
就好，排程腳本每天早上會去線上抓最新設定。

## 斷網會怎樣
- **播過至少一次之後斷網**：瀏覽器有離線快取（service worker），照常播放。
- **從來沒播過就斷網**：會改用隨 ZIP 一起下載的本機備份檔
  `C:\成語卡\output\播放\index.html`，內容是打包當下那一版。
- 兩者都失敗才會是空白畫面。

## 不想再自動播放了
用系統管理員身分執行 `windows\移除排程.ps1`，會把兩個排程工作移除乾淨。

## 疑難排解
| 現象 | 可能原因 / 處理 |
|---|---|
| 07:30 沒有自動播放 | 檢查當時是否已登入那個 Windows 帳號；到「工作排程器」看 `成語卡_開始播放` 的「上一次執行結果」 |
| 全螢幕視窗一直沒消失 | 到「工作排程器」執行一次 `成語卡_停止播放`，或 Alt+F4 |
| 畫面內容是舊的 | 確認 Mac 端有 push 成功；瀏覽器離線快取是「先連網路、連不到才用快取」，有網路就一定是最新的 |
| 出現「執行原則」/「running scripts is disabled」 | 學校用群組原則鎖了 PowerShell 腳本。這種情況每天的自動啟動也會失敗，請找資訊組長解鎖，或回報改用不受限制的 .bat 版本 |
| 找不到瀏覽器（結束碼 2） | 這台電腦需要裝 Microsoft Edge 或 Google Chrome 其中一種 |
| 網頁顯示 404 | GitHub Pages 還沒啟用或還在部署，等幾分鐘再試 |
