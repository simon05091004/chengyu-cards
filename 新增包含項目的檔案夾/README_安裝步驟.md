# 教室電腦安裝步驟（只需要做一次）

這份給「學校大螢幕接的那台 Windows 電腦」用。目標：每個上課日早上
**07:30 自動全螢幕播放成語卡、08:30 自動關閉**，不需要人手動操作。

## 你會需要
- 整個 `成語自動化產出` 資料夾（複製到教室電腦上）
- 那台電腦有安裝 Microsoft Edge（Windows 內建就有）或 Google Chrome
- 一次系統管理員權限，把排程裝上去（後面只有這一步需要）

## 步驟

### 1. 把安裝包複製到教室電腦
Mac 端跑一次：

```bash
python3 scripts/打包教室電腦.py
```

會產生 `output/教室電腦安裝包.zip`。用隨身碟或雲端硬碟帶到教室電腦，
**解壓縮後把裡面的 `成語卡` 資料夾整個放到 `C:\`**，也就是最後會看到：

```
C:\成語卡\data\播放設定.json
C:\成語卡\output\播放\index.html
C:\成語卡\windows\安裝排程.ps1  ...
```

> ⚠️ 不要直接複製整個 `成語自動化產出` 專案資料夾過去——裡面的 `金鑰.txt`
> 是你的 Gemini API 金鑰，不應該放在學校共用電腦上。安裝包已經排除它，
> 也排除了教室電腦用不到的 Python 腳本和圖檔。

> 存放位置建議用本機路徑（`C:\成語卡\`）。放在 OneDrive／Google 雲端硬碟
> 同步資料夾裡也能動，只是開機當下若還在同步，有機會讀到舊檔。

### 2. 安裝排程（只做這一次）
1. 開始功能表打「PowerShell」，找到 **Windows PowerShell**，右鍵 →
   **「以系統管理員身分執行」**
2. 輸入（換成你實際放的路徑）：
   ```powershell
   cd "C:\成語卡\windows"
   powershell -ExecutionPolicy Bypass -File .\安裝排程.ps1
   ```
3. 看到「安裝完成！」就表示兩個排程工作都建好了：
   - `成語卡_開始播放`（每天 07:30）
   - `成語卡_停止播放`（每天 08:30）

這兩個排程只會在「現在登入的這個 Windows 帳號」有登入時觸發。如果教室電腦
平常是同一個帳號、早上會登入或本來就開著，就不用再做別的設定。

### 3. 馬上測試看看
不用等到明天早上，在 `windows` 資料夾裡直接雙擊 **`立即測試.ps1`**
（或右鍵→使用 PowerShell 執行），會用一般視窗（不會鎖全螢幕）立刻開始輪播，
確認畫面、字體、內容都正常。

想測試「真的全螢幕 kiosk 效果」，可以手動改一下 Windows 系統時間到
07:30–08:30 之間，再開始功能表找「工作排程器」，在工作清單裡找到
`成語卡_開始播放`，右鍵→執行；測完記得改回正確時間，並在
`成語卡_停止播放` 上右鍵→執行，把全螢幕視窗關掉。

### 4. 緊急要離開全螢幕怎麼辦
kiosk 模式下按 **Alt+F4** 可以關閉視窗。如果連不上（例如鍵盤沒接），
到「工作排程器」手動執行一次 `成語卡_停止播放` 也可以強制關閉。

## 以後有新成語時怎麼更新這台電腦
在 Mac 那邊照平常流程更新 `data/成語資料.json` 後，跑：
```bash
python3 scripts/全部更新.py
```
然後只要把這**一個檔案**複製、覆蓋到教室電腦：

```
output/播放/index.html  →  C:\成語卡\output\播放\index.html
```

成語內容（注音、例句、複習清單）全部都包在這個 HTML 裡，所以換新成語只要換它。
`data/播放設定.json` 只有在你改了學期起訖、停課日或播放時段時才需要一起覆蓋。

不需要重新執行「安裝排程.ps1」，排程不用重裝，隔天早上就會播新內容。

## 學期／假日設定
`data/播放設定.json` 裡的「學期起訖」「停課日」目前只先填了教育部/人事總處
公告、全國適用的假日；貴校自己的教師研習日、運動會等如果那天早自習不播放，
要自己在這個檔案的「停課日」裡加一筆，然後照上面「以後有新成語時怎麼更新」
的方式重新產生、複製過去。

## 不想再自動播放了
用系統管理員身分執行 `windows\移除排程.ps1`（作法同「安裝排程.ps1」），
會把兩個排程工作都移除乾淨。

## 疑難排解
| 現象 | 可能原因 / 處理 |
|---|---|
| 07:30 沒有自動播放 | 檢查電腦當時是否已登入那個 Windows 帳號；「工作排程器」裡看 `成語卡_開始播放` 的「上一次執行結果」 |
| 全螢幕視窗一直沒消失 | 手動到「工作排程器」執行一次 `成語卡_停止播放`，或直接 Alt+F4 |
| 畫面內容是舊的成語 | Mac 端跑完 `全部更新.py` 後，記得要把新檔案複製、覆蓋到這台電腦 |
| 週末/假日誤開 | 檢查 `data/播放設定.json` 的「學期起訖」「停課日」是否正確覆蓋到這台電腦上的同一個檔案 |
| 找不到瀏覽器（結束碼 2） | 這台電腦需要有裝 Microsoft Edge 或 Google Chrome 其中一種 |
| 出現「無法載入檔案…執行原則」「running scripts is disabled on this system」 | 學校電腦被群組原則鎖住 PowerShell 腳本。這種情況下每天的自動啟動也會一起失敗，不是只有安裝而已。請找資訊組長解鎖，或回來告訴我，我改做成不受執行原則限制的 .bat 版本 |
| 安裝時說找不到播放頁/設定檔 | 只複製了 `windows` 資料夾。要把整個「成語卡」資料夾（含 `data` 和 `output\播放`）一起放到 `C:\` |
