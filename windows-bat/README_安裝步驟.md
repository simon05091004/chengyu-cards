# 教室電腦安裝步驟（.bat 版，不受 PowerShell 執行原則限制）

學校電腦如果鎖了 PowerShell 腳本（執行 `.ps1` 會跳出「執行原則」或
「running scripts is disabled on this system」），就用這個資料夾裡的
`.bat` 版本，**完全不會用到 PowerShell**。

建立排程用的是 Windows 內建的 `schtasks.exe`，那是系統原生執行檔，
不受執行原則管轄。

## 安裝（只需要做一次）

### 1. 下載
在教室電腦的瀏覽器開：

```
https://github.com/simon05091004/chengyu-cards
```

綠色 **Code** 按鈕 → **Download ZIP**。

### 2. 解壓縮放到 C:\
解壓後得到 `chengyu-cards-main`，改名成 `成語卡`，整個放到 `C:\` 底下。
確認這個檔案存在：

```
C:\成語卡\windows-bat\install.bat
```

### 3. 安裝
**直接雙擊 `install.bat`**。

看到這樣就成功了：

```
[OK] Installed. Two tasks now exist:

     ChengyuCard_Start    Mon-Fri  07:30
     ChengyuCard_Stop     Mon-Fri  08:30
```

如果出現 `[x] Could not create the scheduled task.`，那就改成
對 `install.bat` 按右鍵 →「**以系統管理員身分執行**」再跑一次。

### 3.5 設定電源（很重要）
對 **`setup-power.bat`** 按右鍵 →「以系統管理員身分執行」。

它會把這台電腦設成（插電時）**永不睡眠、螢幕永不關閉、允許喚醒計時器**。

為什麼要這樣：排程只有在電腦醒著時最可靠。雖然安裝時也會嘗試開啟「喚醒電腦
以執行此工作」，但喚醒這條路還有兩個變數——電源選項要允許喚醒計時器，而且
如果系統設定成「喚醒時需要重新登入」，畫面會停在鎖定畫面，成語卡開在後面反而
沒人看得到。**讓它不要睡，是最單純可靠的做法。**

### 4. 測試
雙擊 **`test-now.bat`** → 會用一般視窗打開播放頁並立刻開始輪播，
用來確認網路通、畫面正常、字級在大螢幕上讀得清楚。

雙擊 **`status.bat`** → 顯示兩個排程是否存在、上次執行時間、下次執行時間。
有問題時把這個畫面拍給我最有幫助。

## 每天會發生什麼

| 時間 | 動作 |
|---|---|
| 週一～週五 07:30 | `ChengyuCard_Start` 觸發 → 全螢幕打開成語卡網頁 |
| 週一～週五 08:30 | `ChengyuCard_Stop` 觸發 → 關閉瀏覽器 |
| 週六、週日 | 排程根本不會觸發（觸發器只設定週一到週五） |
| 國定假日、停課日 | 排程仍會觸發，但**網頁自己會判斷**，顯示「今天不播放（原因）」的待機畫面，08:30 一樣會關掉 |

假日那天畫面上只會有一個安靜的待機畫面，不會播成語——學校沒人在，不影響任何事。

## ⚠️ 一個要知道的取捨

`stop-player.bat` 在 08:30 會關掉**該瀏覽器的所有視窗**（預設是 Edge）。
純批次檔沒辦法只精準關掉某一個視窗。

所以請養成這個習慣：

- **Edge 留給成語卡自動播放用**
- **自己上課用 Chrome**

這樣 08:30 關閉時就不會動到你正在用的東西。

（PowerShell 版沒有這個限制，它能精準只關自己開的那個視窗。如果學校之後解鎖了
PowerShell，可以改用 `windows` 資料夾裡的版本。）

## 以後有新成語時
**這台電腦完全不用動。** 老師在自己的電腦上更新並 push 到 GitHub，
教室電腦隔天早上就會自動播到新內容。

播放時段、停課日的設定也一樣是線上的，改完 push 就生效。

## 不想再自動播放了
雙擊 `uninstall.bat`，兩個排程會被移除乾淨。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `install.bat` | 安裝排程（跑一次就好） |
| `setup-power.bat` | 設定永不睡眠、螢幕不關（跑一次就好，需系統管理員） |
| `start-player.bat` | 07:30 自動執行，不用手動點 |
| `stop-player.bat` | 08:30 自動執行，不用手動點 |
| `test-now.bat` | 隨時預覽畫面 |
| `status.bat` | 查排程狀態、上次執行結果 |
| `uninstall.bat` | 移除排程 |

## 疑難排解

| 現象 | 處理 |
|---|---|
| 雙擊 install.bat 閃一下就消失 | 用「以系統管理員身分執行」再試一次；或先開 `cmd`，把 install.bat 拖進去按 Enter，就能看到訊息 |
| 07:30 沒反應 | 跑 `status.bat` 看「上次執行時間」和「上次結果」，拍給我 |
| 電腦早上是睡眠狀態 | 跑過 `setup-power.bat` 就不會睡了。若仍要靠喚醒，需確認工作排程器裡該工作的「條件」分頁有勾「喚醒電腦以執行此工作」，且系統沒有設定喚醒後須重新登入 |
| 電腦早上是**完全關機** | 軟體無解。要嘛前一天別關機，要嘛進主機 BIOS/UEFI 設定每日定時開機（各家主機設定位置不同，通常在 Power Management 裡找 RTC Alarm / Wake on Alarm） |
| 上次結果顯示 `2` | 這台電腦找不到 Edge 或 Chrome，需要裝其中一個 |
| 畫面出來但是空白 | 學校網路連不到 GitHub，`test-now.bat` 也會打不開網頁，請告訴我 |
| 全螢幕關不掉 | 按 Alt+F4，或雙擊 `stop-player.bat` |
| 想確認排程存不存在 | 跑 `status.bat`，比在工作排程器裡翻清單可靠 |
